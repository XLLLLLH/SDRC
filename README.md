Abstract
Deep quantization coding is widely used in large-scale image retrieval because it combines compact representation with efficient distance computation. Existing frameworks typically adopt differentiable soft quantization for end-to-end training and hard quantization for efficient inference. However, the discrete nature of hard quantization causes semantic information loss, leading to a persistent gap between training-procedure representation quality and inference-procedure retrieval accuracy. To bridge this gap, we propose a self-distillation framework that transfers ranking knowledge from soft-quantization representations to their hard-quantization counterparts within a single network. Specifically, a ranking consistency loss encourages hard quantization to reproduce the retrieval order induced by soft quantization, while a feature similarity loss reduces their feature-level discrepancy and stabilizes ranking supervision. Extensive experiments on CIFAR-10, FLICKR25K, and NUS-WIDE demonstrate that the proposed method achieves competitive or superior performance compared with state-of-the-art unsupervised retrieval methods.
